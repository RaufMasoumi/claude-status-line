Neon Status Line

A status line for Claude Code that shows the model, effort level, context use, and your 5-hour and weekly limits. One Python file, no packages, nine themes.

Source and install commands: github.com/RaufMasoumi/claude-status-line

What it shows

Model
The model this session is using.
Effort
Low to max, lit as 1–5 bars in the neon themes.
ctx
How full the context window is.
5h
Your 5-hour limit used, and when it resets.
wk
Your weekly limit used, and when it resets.

Usage turns yellow at 50% and red at 80%, in every theme.

The line fits your terminal. Meters grow to fill a wide terminal, and in a narrow one the line drops detail step by step: reset times (kept once a limit is at 80%), then the effort word, then the meters, then the model's version number. It never wraps.

Themes

Real output of the script with sample values, at each theme's natural size. The bar under each theme shows that width; the tick marks 80 columns, about a terminal on a third of a 1920px screen. In Claude Code every theme then stretches or shrinks to your terminal. Try a width with python statusline.py --preview neon --width 60.

Install

  1. Save the script

    Copy the script from the bottom of this page and save it as statusline.py in your Claude folder: C:\Users\<you>\.claude\ on Windows, ~/.claude/ on macOS and Linux. It needs Python 3.8 or later.

  2. Point Claude Code at it

    Add this to your user settings, ~/.claude/settings.json, keeping the settings already there. refreshInterval redraws the line every 3 seconds, so it adjusts soon after you resize the terminal.

    Windows 
    "statusLine": {
  "type": "command",
  "command": "python C:/Users/<you>/.claude/statusline.py",
  "padding": 0,
  "refreshInterval": 3
}
    macOS / Linux 
    "statusLine": {
  "type": "command",
  "command": "python3 ~/.claude/statusline.py",
  "padding": 0,
  "refreshInterval": 3
}

  3. Pick a theme

    From your Claude folder, preview every theme in color, then choose one. The status line switches on its next refresh. Without a choice you get classic.

    python statusline.py --preview
python statusline.py --set neon-mini

Good to know

  • 5h and wk show -- at first. Claude Code sends usage only on a Claude.ai plan, and only after Claude's first reply in a session.
  • Effort comes from what Claude Code sends. If it sends none, the script uses the effort saved in your settings.json.
  • powerline needs a font with powerline arrows, such as Cascadia Code (the Windows Terminal default) or any Nerd Font. If you see boxes, use pills.
  • Set STATUSLINE_THEME to override the saved theme, or STATUSLINE_DEBUG=1 to save what Claude Code sends to ~/.claude/statusline-input.json.
